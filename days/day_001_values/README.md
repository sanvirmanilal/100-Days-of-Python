# Day 001: Values and return statements

**Phase:** Foundations

**Prerequisites:** None; begin here.

## Learn

Variables bind names to values. A function returns a value to its caller; printing only displays it. Start with short, explicit expressions.

Read and predict the example output before running it. Change one input, predict again, and explain the result.

```powershell
python practice.py 1 --examples
```

The worked examples teach the topic. The exercise file contains only contracts and unfinished stubs.

## Exercises

### 1. Foundation: `greet(name)`

Return "Hello, NAME!" with name inserted exactly as supplied.

```powershell
python practice.py 1 --exercise 1
```

### 2. Application: `describe(name, age)`

Return "NAME is AGE years old." Assume age is a nonnegative integer.

```powershell
python practice.py 1 --exercise 2
```

### 3. Stretch: `swap_values(left, right)`

Return a tuple containing right then left, preserving their types.

```powershell
python practice.py 1 --exercise 3
```
