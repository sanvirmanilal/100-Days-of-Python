# Day 002: Arithmetic and numeric types

**Phase:** Foundations

**Prerequisites:** Complete days 001–001 first.

## Learn

Integers represent whole numbers; floats approximate real numbers. Compare / with // and %. Parentheses make calculation order explicit.

Read and predict the example output before running it. Change one input, predict again, and explain the result.

```powershell
python practice.py 2 --examples
```

The worked examples teach the topic. The exercise file contains only contracts and unfinished stubs.

## Exercises

### 1. Foundation: `minutes_to_seconds(minutes)`

Return minutes multiplied by 60. Accept nonnegative integers.

```powershell
python practice.py 2 --exercise 1
```

### 2. Application: `rectangle_area(width, height)`

Return width times height; dimensions are nonnegative numbers.

```powershell
python practice.py 2 --exercise 2
```

### 3. Stretch: `split_seconds(total)`

Return (hours, minutes, seconds) with minutes and seconds in 0..59. total is a nonnegative integer.

```powershell
python practice.py 2 --exercise 3
```
