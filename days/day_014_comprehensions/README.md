# Day 014: Comprehensions

**Phase:** Working with collections

**Prerequisites:** Complete days 001–013 first.

## Learn

A comprehension expresses mapping or filtering concisely. Keep it readable; use a loop for complicated state or multiple decisions.

Read and predict the example output before running it. Change one input, predict again, and explain the result.

```powershell
python practice.py 14 --examples
```

The worked examples teach the topic. The exercise file contains only contracts and unfinished stubs.

## Exercises

### 1. Foundation: `squares(n)`

Return squares of integers 0 through n-1; n >=0.

```powershell
python practice.py 14 --exercise 1
```

### 2. Application: `length_map(words)`

Return a dictionary mapping each distinct word to its length.

```powershell
python practice.py 14 --exercise 2
```

### 3. Stretch: `flatten(matrix)`

Return a list of all row items in row order; rows may be empty.

```powershell
python practice.py 14 --exercise 3
```
